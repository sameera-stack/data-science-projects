# Data Science Projects

Projects using Python, Pandas and Matplotlib.

## Projects

### California Housing Data Analysis
Exploratory analysis of the California housing dataset (17,000 rows, 9 columns): summary statistics, missing-value checks, price distribution and the relationship between median income and house value.

- Notebook: [housing_data_analysis.ipynb](housing_data_analysis.ipynb)
- Tools: Python, Pandas, Matplotlib
